A mean-reversion bot for CBBTC/USDC over one-minute bars: it buys when the close
sits far enough under its trailing mean to pay for the round trip, and sells the
bounce or the profit. Long only, one position at a time, every decision read from
the bars already sent.

## Run it

```sh
python3 -P -s main.py
```
